# 拾纷电商管理系统（微信小程序）

一个面向天猫店铺风格的微信小程序仓库管理系统，覆盖仪表盘、库存、入库、退货入库、出库与成本登记。

## 页面功能

- **公司代码验证**：进入系统前需要输入公司代码，默认代码为 `sfds`，登录页不会展示默认代码。
- **首页仪表盘**：展示代发总成本、库存数量、库存总金额、库存预警、供应商货款余额、今日出入库、本月累计出入库数据。
- **库存管理**：支持登记商品名称、规格、单价、在库数量、供应商、备注、预警数量，并维护供应商货款余额。
- **入库管理**：支持按日期筛选，支持从库存商品下拉选择商品名称、规格、单价，并编辑记录。
- **退货入库管理**：支持按日期筛选，支持从库存商品下拉选择商品名称和规格，并编辑记录。
- **出库管理**：支持按日期筛选，支持从库存商品下拉选择商品名称、规格、单价，并维护成本登记。
- **记录操作**：各类登记列表均提供编辑入口，并提供一键全选/取消选择能力。

## 本地检查

```bash
npm run check
```

该命令会校验小程序 JSON 配置文件格式。
